# Romone Dunlop

Year 12 software builder in Australia working across financial intelligence, healthcare technology, applied AI, research systems, and production software for external organisations.

**Primary languages:** Python · Rust · TypeScript · SQL

## Current work

- **Autonomous Market Intelligence & Decision System** *(research-stage)* — building a point-in-time financial research system that turns corporate disclosures and market data into evidence-grounded event representations, historical analogue retrieval, calibrated outcome distributions, uncertainty estimates, and eventually a separately gated autonomous research-to-execution loop.
- **Bloom** *(active development / pilot-stage)* — building longitudinal cognitive-monitoring software for participants, caregivers, and clinicians; the current pilot footprint spans 10 clinics.
- **MindBridge Health** *(active development)* — building an AI-assisted clinical intake and triage platform for structured patient-to-clinician handoffs.
- **Pathway to Entry** — building regional post-school pathway infrastructure now used across 40+ schools, with 103 funding opportunities and 59 key pathway dates consolidated into one system.
- **Callable** *(pre-release / work in progress)* — open-source infrastructure that turns reviewed business workflows into auditable, agent-callable commands.
